# 聚合助手：点歌与 QQ 群管

从 v1.4.0 起，签到、积分、排行榜、每日老婆独立为 [astrbot_plugin_checkin_wife](https://github.com/tree-people-Z/astrbot_plugin_checkin_wife)。本插件保留点歌、歌单和 QQ 群管理。

## 拆分升级

请同时安装独立签到插件 v1.0.0 和本插件 v1.4.0。旧版 v1.3.0 应先停用/更新，避免与独立插件重复注册同名指令和 LLM 工具。

独立插件首次加载前运行其 `scripts/migrate_config.py`，复制旧签到配置；首次启动自动复制旧积分、签到、老婆、换老婆次数及已保存图片。旧库保留，歌单和群管继续使用本插件数据库。详细步骤见独立插件的 README。

已有 QQ 指令面板可继续使用：签到/老婆由独立插件响应，点歌/歌单由本插件响应。更新后旧消息中的按钮失效，请获取新消息再操作。面板同步脚本现在仅管理点歌与歌单条目；不要在尚未配置独立面板时覆盖现有综合面板。

## 功能

### QQ点歌
| 指令 | 说明 |
| --- | --- |
| `点歌 <歌名>` | 搜索并选歌，可结尾序号直接选定（如 `点歌 稻香 2`） |
| `查歌词 <歌名>` | 查询歌词 |
| `歌单添加 <歌名>` / `我的歌单` / `播放歌单 <序号>` / `删除歌单 <序号>` / `清空歌单` | 用户歌单 |

> 音源为 QQ 音乐（聚合接口 `https://music.txqq.pro/`，可在配置中替换）。配置 `music_card_api_key` 时，QQ OneBot 优先发送签名 Ark 卡片，避免部分 QQ 客户端对普通卡片显示“发送者版本过低”；没有 Key 或签名服务失败时再尝试普通卡片，之后按配置回退语音和文本链接。

### QQ群管（仅 QQ）
- 禁言/解禁/全禁、踢人/群拉黑、撤回、改名、群公告、群友信息
- 违禁词（自定义 + 内置）、刷屏检测、宵禁
- 进阶（配置开启）：头衔、上管/下管、改群名、改群头像
- 权限：超级管理员 > 群主 > 管理员 > 成员
- `/群管帮助` 查看指令列表


## 对话与消息

自然语言调用 AstrBot 默认 Agent 工具，插件发送完整 Markdown 结果后仅向模型返回发送状态。普通聊天格式保持 AstrBot 默认方式。

传统指令默认关闭，可通过 `command_enable` 开启。QQ 官方群聊/C2C 支持歌曲候选播放、歌单刷新等按钮；QQ 群管依赖 OneBot/NapCat，QQ 官方平台不支持这些群管动作。

## 配置与数据

WebUI 中配置 `music_*`、`admin_*`、请求超时、代理及 QQ 按钮。`llm_capability_hint` 控制向模型提供能力提示。主动回复由 AstrBot 自身配置管理。

数据保存在 `data/plugin_data/astrbot_plugin_allinone/allinone.db`。更新保留旧积分、老婆表作为迁移源及历史副本；本插件不再使用它们记分。歌单与群设置继续在此库读写。
