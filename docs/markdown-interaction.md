# 点歌与群管的 Markdown 交互

只有插件发送的结果设置 Markdown，普通聊天继续走 AstrBot 默认 Agent 管线。搜索结果附播放第 1～4 首及我的歌单按钮；歌单附刷新歌单及功能帮助按钮。按钮使用 `/aio_action`，与独立签到插件的 `/checkin_wife_action` 区分。

QQ 官方群聊/C2C 支持 keyboard，其他平台回退文字入口。凭据绑定用户、聊天来源、日期和有效期，每次仅可使用一次；发送失败回退文字，不重新执行业务。

歌词保留逐行引用，外部昵称、歌名和歌手名转义；群管结果采用标题、重点数字与短列表。签到和老婆的排版及交互方案见独立插件 `docs/markdown-interaction.md`。
